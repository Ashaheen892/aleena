# مصنع أصول التصميم — الكلمة: صمم

الكلمة المختصرة المتفق عليها هي **صمم**. اسم المتجر **ألينا** و **aleena** يشغّلان نفس المسار. نفّذ كل المراحل في طلب واحد. لا تنتظر موافقة بين المراحل، ولا تكتفِ ببرومبتات أو مجلدات فارغة إذا كانت أداة توليد الصور متاحة.

## ما يُستخرج وما لا يُخترع

1. اقرأ `twilight.json` و `src/assets/styles/01-settings/global.scss` و `src/locales`.
2. شغّل التحليل:

```bash
npm install --prefix scripts/design-factory
node scripts/design-factory/analyze.mjs
```

3. التصنيفات الحية في هذا الثيم فارغة (`selected` و `options`). العناوين الوحيدة الموجودة هي روابط تجريبية في `home.main-links` و `home.circular-links`. استخدمها كما هي بعد حذف التكرار، ولا تستبدلها بقائمة عطور أو مكياج أو أي نشاط غير مكتوب.
4. إذا لم يوجد نشاط تجاري فاتركه `null`. لا تخترع اسماً تجارياً أو جمهوراً.
5. إذا أضاف المستخدم في نفس الرسالة قائمة تصنيفات أو نشاطاً صريحاً، فهذه بيانات طلبه. اكتبها في `scripts/design-factory/request.json` وحدّث `jobs.json` قبل التوليد. نشاط «متجر عطور» يستخدم تصنيفات العطور من البرومبت الرئيسي ما لم يكتب المستخدم قائمة أخرى: عطور نسائية، عطور رجالية، عطور للجنسين، عطور الشعر والجسم، معطرات المنزل والسيارة، الفحم والبخور، عطور أطفال.
6. إذا بقي النشاط غير معروف ولا توجد تصنيفات فرعية، اترك `04-خلفيات-التصنيفات-المستطيلة` فارغاً وسجّل السبب. إذا حُدد نشاط، اصنع خلفية أفقية 1200×500 لكل تصنيف من هذا النشاط بتكوين مختلف عن الصورة المربعة، وسجّل أنها ليست شجرة فرعية مستخرجة من الثيم.

## الشعار

- لا يوجد ملف شعار أصلي. لا تنزل شعاراً من رابط غير موجود في الملفات.
- ارسم كلمة «ألينا» بخط Noto Sans Arabic عبر Pango حتى تتشكل الحروف العربية بشكل صحيح. ثبّت الأداة عند غيابها: `sudo apt-get install -y pango1.0-tools` ثم:

```bash
node scripts/design-factory/render-logo.mjs
```

- ثلاث نسخ شفافة: لون الثيم `#414042`، أسود، أبيض. `logo-original.png` نسخة من لون الثيم مع توضيح أنها ليست شعاراً تاريخياً.
- الفافيكون رمز حرف الألف فقط، لأن الاسم الكامل لا يُقرأ عند 32 بكسل.
- خلفية شفافة حقيقية، بلا إطار ولا ظل ولا موك أب.

## الصور

ولّد كل ملف في `scripts/design-factory/jobs.json` بأداة توليد الصور، ثم انقله إلى المسار `source`. المواصفات داخل البرومبت:

- بلا أي حروف أو أرقام أو شعارات أو علامات مائية.
- بلا وجوه أو أيدٍ أو عبوات تحمل علامة تجارية حقيقية.
- لوحة الثيم: فحمي `#414042` وأسود `#1D1F1F` ولمسة مرجانية خفيفة `#ff6767`.
- كل تصنيف مشهد مختلف. البنرات الخمسة تكوينات مختلفة: فاخر، عائم، بسيط، سينمائي، عرض إبداعي، مع المحتوى المهم في منتصف الارتفاع لأن القص إلى 1916×821 يقص الأعلى والأسفل.
- الخلفيات العشر بلا منتج مزدحم، وفيها مساحة هادئة ليضع الثيم النص لاحقاً.
- المربعات `aspect_ratio` = `1:1`. البنرات والخلفيات `16:9`.

بعد اكتمال المصادر:

```bash
node scripts/design-factory/optimize.mjs
node scripts/design-factory/pack.mjs
```

`optimize.mjs` يثبت الأبعاد ويخفض جودة WebP حتى الحد: 50KB للمربع 800×800، و500KB للبنر 1916×821 وللخلفية 1920×1080، دون تغيير المقاس. احذف `_inbox` بعد نجاح الضغط حتى لا تُرفع الأصول الخام.

## التسليم

- المجلد المطلوب هو `store-design-assets/` بشجرته الكاملة.
- `pack.mjs` ينسخه إلى `~/Desktop/ألينا/` أو `~/سطح المكتب/ألينا/` إذا وُجد المجلد.
- إذا لم يوجد سطح مكتب، فالرابط المباشر هو ملف `aleena-store-design-assets.zip` عبر مسار GitHub raw الذي يكتبه التقرير.
- التقرير النهائي الوحيد هو `store-design-assets/07-تقارير-التصميم/assets-report.json`. لا تدّعِ فحصاً لم يُنفَّذ. فحص النص والتشوه البصري غير آلي في هذه البيئة ويبقى مذكوراً كذلك.

## تحقق سريع

- الشعارات PNG وفيها قناة ألفا، وزواياها شفافة.
- كل WebP بالمقاس المطلوب وتحت سقفه أو مُبلَّغ عنه بالاسم.
- لا ملفين بنفس بصمة SHA-256.
- مجلد التصنيفات الفرعية موجود وفارغ وسببه مكتوب في التقرير.
